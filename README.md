# AtliQ Hardware: Sales & Finance Analytics Report (Excel)

A sales and finance report built in Excel with **Power Query, Power Pivot, DAX and PivotTables**, covering multiple fiscal years and about **800,000 rows** of data. The report automates data preparation and gives leadership a clear view of profitability, market performance and product performance.

## Business Problem

AtliQ Hardware needed a reliable way to analyse sales and financial performance across multiple fiscal years. The raw data was large (about 800K rows) and cleaning it by hand was slow and repetitive.

**Goal:** build a Sales & Finance Analytics Report that tracks key KPIs (Net Sales, COGS, Gross Margin) and automates the manual data work, so decisions can be made faster.

## Results at a Glance

| Outcome | Impact |
|---|---|
| Data cleaning automated with Power Query | About 4 hours of manual effort saved |
| Overall data processing time | Reduced by 50% |
| Reporting | One data model feeding multiple P&L, market and product reports |
| Decision-making | Faster, data-driven decisions and better resource allocation |

## Key KPIs

- **Net Invoice Sales and Net Sales**
- **COGS** (Cost of Goods Sold)
- **Gross Margin**
- **Performance vs Target**

## What I Built

1. **Automated data cleaning (Power Query):** replaced repetitive manual cleaning with a refreshable process.
2. **Data model (Power Pivot):** connected the data into one model for fast analysis on a large dataset.
3. **DAX measures:** wrote dynamic measures for the financial metrics, so every report updates from the same logic.
4. **PivotTable reports:** designed the reports listed below.
